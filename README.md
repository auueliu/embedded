## Concept

Language is not a list. Words exist in relation to each other. **Embedded** visualizes this as a three-dimensional space you can move through.

The title refers to _word embeddings_, a technique used in machine learning where words are represented as points in high-dimensional space, positioned by semantic similarity. What would it feel like to inhabit that space?
